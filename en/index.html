Inside the Network

Network

▾ Getting started: what is a neural network?

A neural network is a mathematical model that transforms input values into one or more output values. To do this, it connects simple computational units called neurons. Despite the biological-sounding name, here they are simply mathematical units connected to one another. Each neuron processes its inputs and produces a value called an activation.

Neurons are arranged in layers. The input layer receives the data, while the output layer produces the result. Any intermediate layers are called hidden layers because their activations remain internal to the network.

In the input layer, the activations are simply the input values supplied to the network after the normalization described below.

Each neuron in a hidden or output layer receives the activations produced by the previous layer. We denote these activations by a1, a2, … and the weights of the corresponding connections by w1, w2, …. The neuron multiplies each activation by the weight of its connection, adds the results, and then adds a bias b:

z = w1a1 + w2a2 + … + b = Σi wiai + b

The sign and size of each weight determine how the activation carried by that connection affects the neuron. The bias is an additional term that shifts the neuron’s combined input z. This value is then transformed by the activation function f:

a = f(z)

The available functions are described in the Activation functions guide under Controls.

In hidden layers, a nonlinear activation function allows the network to represent relationships and boundaries more complex than a straight line. Without this nonlinearity, adding more hidden layers would still produce only linear decision boundaries—straight lines when the problem has two input variables.

The activation a is then passed to the next layer, and so on. The activations of the final layer are the network’s output values.

Before training, all weights are initialized randomly from a uniform distribution between −1 and 1, and biases start at 0. Larger networks typically use random initialization scaled for each layer, depending on its size and activation function.

During training, the network uses examples whose expected results are known. A loss function measures how far the network’s outputs are from those results. The network gradually adjusts its weights and biases to reduce the mean loss on the training examples. In other words, the rule linking inputs to results is not given to the network directly; it is approximated through these updates.

Error can be measured using different functions, with the choice depending on the type of problem. For single-output problems, the app uses squared error, which is proportional to the squared difference between the prediction and the expected output. This is a natural choice for predicting a numerical value and, for simplicity, is also used here for binary classification. For problems with three or more classes, the app uses cross-entropy, one of the most widely used loss functions in real-world classification problems. Cross-entropy assigns a larger error the lower the predicted probability for the correct class. The formulas for both functions appear in One example at a time.

Most problems in this app have two classes: the expected result y is 0 or 1, and the network produces a single output ŷ between 0 and 1. Values below 0.5 are assigned to class 0; values of 0.5 or above are assigned to class 1. In multiclass problems, the network produces one output per class and chooses the class with the largest value. In the sequence problem, a linear output directly represents the predicted numerical value.

After training, the weights and biases can be left unchanged. The network can then process new data whose expected result is unknown and produce a prediction.

The network in this app is deliberately small so that you can inspect its weights, biases, activations, and loss in detail.

▸ Inputs normalized between 0 and 1

All network inputs are rescaled to the same range, from 0 to 1. This transformation is called normalization.

If X is the original input value, the normalized value x used by the network is:

x = (X − Xmin) / (Xmax − Xmin)

where Xmin and Xmax are the endpoints of the original range. This maps Xmin to 0, Xmax to 1, and every intermediate value proportionally between them.

A normalized value is dimensionless and does not depend on the unit used for the original data. For example, over a range from 0 to 10 minutes, 6 minutes becomes (6 − 0)/(10 − 0) = 0.6; over a temperature range from 16 °C to 30 °C, 23 °C becomes (23 − 16)/(30 − 16) = 0.5.

Using a common scale makes learning easier by preventing an input from dominating the calculations simply because its unit happens to produce larger numbers. The network instead learns the relative importance of its inputs by adjusting their weights.

Activation functions guide

Each neuron computes a value z by combining the incoming activations with their weights and adding the bias. The activation function f(z) transforms this signal into the neuron’s activation a. Its derivative—the slope of the tangent line on the graph—shows how quickly the activation changes as z changes and, during training, affects how the error signal propagates and how weights and biases are updated. Different functions can therefore make training easier or harder, faster or slower. In hidden layers, you can compare them while keeping the network and data unchanged; the output-layer function is determined by the type of problem.

Sigmoid

σ(z) = 1 / (1 + e−z)

Property: maps every value to the range from 0 to 1.

Effect in the network: in the output layer of a binary classifier, the result can be interpreted as the estimated probability of class 1. Sigmoid has also been used in hidden layers, but is less common in deep networks today: for large positive or negative z, the curve flattens and its derivative approaches zero, which can make training harder.

tanh

tanh(z) = (ez − e−z) / (ez + e−z)

Property: maps values to the range from −1 to 1 and is centered at zero.

Effect in the network: lets a neuron produce negative, zero, or positive activations and therefore represent contributions in opposite directions. Near z = 0, the activation changes strongly with the signal; for large positive or negative values, however, the curve flattens and the derivative approaches zero, which can make training harder.

ReLU

ReLU(z) = max(0, z)

Property: returns zero for z ≤ 0 and leaves positive values unchanged.

Effect in the network: for z > 0, ReLU does not compress the signal and its derivative is 1, which can speed up training in hidden layers. For z < 0, both the output and derivative are zero: a neuron that remains in this region can stop updating.

Linear

f(z) = z

Property: returns z without limiting it; the derivative is always 1.

Effect in the network: used in the output layer when the network must predict a numerical value.

Softmax

pi = ezi / Σj ezj

Property: softmax is a multivariable function: it takes the output-neuron values z1, …, zk together and returns the same number of values between 0 and 1 whose sum is 1. Each result depends on all the inputs.

Example with three classes
[2, 0, −1]  →  [0.844, 0.114, 0.042] 0.844 > 0; 0.114 > 0; 0.042 > 0 and 0.844 + 0.114 + 0.042 = 1.

Effect in the network: each output neuron corresponds to one class. Softmax converts the input values into positive numbers that sum to 1 and can be interpreted as estimated class probabilities; the network predicts the class with the highest probability. In the example, the first class is selected. In this app, softmax is used only in the output layer of multiclass problems.

Balanced accuracy measures how well the model recognizes the different classes while giving each class equal weight, regardless of how many examples it contains.

For each class, first calculate the fraction of its examples that are classified correctly:

class recall = correctly classified examples in the class / total examples in the class

Then take the arithmetic mean of those values:

balanced accuracy = sum of class recalls / number of classes

Example. Consider a model that has learned no meaningful way to distinguish the classes and simply predicts the majority class every time. If the dataset is strongly imbalanced, with 90 examples of class A and 10 of class B, the model would classify 90 out of 100 examples correctly and achieve 90% overall accuracy.

Looking at the two classes separately, however, it would recognize:

Class A: 90 out of 90 = 100%
Class B: 0 out of 10 = 0%

Its balanced accuracy would therefore be:

(100% + 0%) / 2 = 50%

The 90% overall accuracy comes only from class A being much larger, not from any real ability to distinguish the two classes. By weighting the classes equally, balanced accuracy makes it clear that the model cannot recognize class B.

With k classes, a model that always predicts the same class has balanced accuracy 1/k: for example, 50% with two classes and 33.3% with three.

Likewise, choosing uniformly at random among the classes gives an average balanced accuracy of 1/k. This provides a useful baseline for interpreting model performance.

Guide to Inside the Network

Inside the Network lets you build, train, and explore small neural networks for a range of classification and numerical prediction problems. You can change the network architecture, follow training as it happens, compare performance, and inspect the values produced during the calculations. In the RGB color experiment, you can build the dataset yourself. You can also import your own classification dataset from a CSV or TSV file.

If you are new to the interface, start with Getting started: the main controls. The other sections cover the suggested experiments, the information shown on screen, and the available controls.

Getting started: the main controls

  1. Open Getting started: what is a neural network?, next to the Network heading, for a short introduction to neurons, layers, weights, biases, and training.
  2. In the Controls panel, select an experiment from the Problem dropdown under Problem and data. Each problem determines what data the network receives as input and what it must predict. To work with your own data, choose Import CSV/TSV; see Importing your own data (CSV/TSV) for details.
  3. Under Network architecture, choose the number of hidden layers and the number of neurons in each layer. The app sets the number of input and output neurons automatically for the selected problem.
  4. Use ▶ Train and Pause to start or pause continuous training. While the network is training, you can watch its predictions, performance, and loss curve change. Run one epoch processes the full training set once without starting continuous training.
  5. When the network is paused, select an example and click a connection or neuron to open Network Internals. With One example at a time, you can follow prediction, loss calculation, and parameter updates as separate stages.
  6. ⟲ Reset network creates a new network with freshly initialized weights and biases, then starts again on the same dataset.

Suggested experiments

The menu provides a core sequence of experiments followed by three further investigations using built-in datasets. You can also import your own data. Each built-in experiment includes three panels: The model describes the situation and the rule used to generate the data; Things to try suggests experiments you can carry out; What to look for highlights the main patterns and ideas that may emerge. Some experiments also include a How it works section, which explains a broader neural network concept in the context of the current problem.

When comparing two runs, change one thing at a time and consider the loss, correct predictions, per-class results, and shape of the decision boundary together.

Core sequence

  1. Catching the bus — 0 hidden layers. Both the rule and the decision boundary are linear. This experiment connects weights and bias to the position and slope of the decision line.
  2. Cardiovascular profile — 1 hidden layer. The target region is enclosed by a curved boundary, showing how a hidden layer allows the network to represent a nonlinear separation.
  3. 3×3 checkerboard — 2 hidden layers. Compare networks with the same number of parameters but different architectures to explore the role of depth and the way neurons are distributed across layers.
  4. Classroom comfort and complaints — 4 variables. Each example is described by four variables, so you can explore classification when the input data can no longer be displayed in a single two-dimensional plot.
  5. Bluetooth: two transmitters — 3 classes. The network must assign each input to one of three mutually exclusive classes. It produces three outputs that can be interpreted as estimated class probabilities and predicts the class with the highest value.

Further investigations

  1. Bluetooth: noisy measurements — validation and overfitting. Labels are generated probabilistically, so nearby positions can have different outcomes. This makes both learning and performance harder to interpret. The validation set lets you compare how well the network fits the training data with how well it classifies unseen examples, and explore what changes when the network is made wider or deeper.
  2. RGB colors — build the dataset. Create the dataset by assigning the labels yourself. Compare different networks and ask whether the rule expressed by your examples can be represented by a linear decision boundary.
  3. Number sequences — predict the next term. The network receives four consecutive terms of a sequence and learns to predict the next one. The final part of the sequence is held out of training. It is used for one-step predictions and for an autoregressive continuation, generating one term at a time and feeding the network’s own predictions back in as inputs.

More things to try

For further comparisons, change the architecture, activation function, learning rate, or data sample. Change only one condition at a time, and turn on Fixed seed when you want the experiment to be reproducible.

Understanding the screen

Data

When a problem has two input variables, each example can be shown as a point on the plane. Point colors represent the observed class or outcome, while the background shows the network’s current predictions across the input space.

Show reference boundary draws the geometric rule used to generate the data as a dashed line, so you can compare it with the boundary learned by the network. In Bluetooth: noisy measurements, it marks the distance at which the two outcomes are equally likely. The control is not available when the problem cannot be represented in two dimensions or when no reference boundary is defined, as in the RGB dataset and user-imported datasets.

Click an example to inspect a data point whose label is known. Click an empty part of the plot to give the network a new point and see how it classifies it.

With three or more inputs, the examples are displayed in a table. Select a row to inspect that example in the network. You can also enter new values in the fields above the table and use Classify to ask the network for a prediction. Clear removes only the values you entered and the current selection; it does not delete examples from the dataset.

In the sequence experiment, four consecutive terms are used as inputs and the following term is the value to predict. The graph distinguishes points used for training, points reserved for validation, and any continuation generated recursively by the network. During One example at a time, it also highlights the four current inputs and the corresponding prediction.

Network

Each connection between two neurons is drawn as a line and has an associated weight: teal for a positive weight and red for a negative one. Thicker lines represent weights with larger absolute values.

Circles represent neurons. For input neurons, the color depends on the normalized input value. For all other neurons, it depends on the activation or output value. White represents 0, teal positive values, and red negative values. Color intensity increases with the absolute value.

Hidden and output neurons also display their bias. See Inputs normalized between 0 and 1 for an explanation of how input values are rescaled.

Current performance

Mean loss is the average value of the loss function over all examples in the relevant set, using the network’s current parameters. It measures how far the numerical outputs are from their expected values. Correct predictions shows how many examples the network classifies correctly, both overall and separately for each class.

The How is balanced accuracy calculated? panel explains how this measure is computed and why it is useful.

When a validation set is available, Training and Validation results are shown separately. In the RGB experiment and imported datasets, validation appears only when there are enough examples.

In the sequence experiment, validation measures one-step prediction: each term is predicted from the actual preceding terms. The panel below the graph instead compares the most recently generated term with the corresponding true value.

Loss over time

The graph shows the mean training loss after each epoch. When a validation set is available, a second curve shows the loss on examples that do not update the network.

The dashed line shows the value measured after each epoch. The thicker solid line shows a moving average over up to 17 nearby epochs, smoothing out short-term fluctuations. Y-axis zoom in ×10 and Y-axis zoom out ×10 change the vertical scale: the first reduces the displayed y-range to one tenth of its current size, while the second increases it tenfold. This makes it easier to inspect losses that differ by several orders of magnitude.

Controls and reproducible experiments

▶ Train starts continuous training. While training is running, the same button becomes Pause.

Run one epoch completes the current epoch, or processes the entire training set once if a new epoch has just started. One complete pass through the training set is called an epoch. Before the next epoch, the order of the training examples is shuffled.

One example at a time breaks the network’s work on a single example into three stages: prediction, loss calculation, and parameter update.

⟲ Reset network recreates the network with newly initialized weights and biases. Changing the architecture or activation function also restarts training on the same dataset.

The Learning rate η controls the size of the updates applied to weights and biases. The formulas are explained in the weight and bias inspection panels.

Speed controls how many epochs per second the app attempts to run. If the device cannot keep up with the requested speed, the app automatically reduces it and displays a warning.

For hidden layers, you can choose tanh, sigmoid, or ReLU and compare them while keeping the network and data unchanged. The Activation functions guide brings together their formulas, graphs, and main properties.

The seed initializes the random number generator. Keeping the seed fixed makes experiments reproducible. With Fixed seed enabled, ⟲ Reset network reuses the same initial weights and biases.

For built-in problems, New data generates another sample and restarts training. With a fixed seed, the network initialization stays the same; without it, the initial weights and biases also change. In the RGB experiment, the same control becomes Clear colors and clears the collected colors after confirmation. For imported datasets, New data is not shown. To use another file, choose Import CSV/TSV; the new dataset replaces the previously imported one.

Classify sends the values you entered to the network in problems that are not displayed directly on the two-dimensional plane.

In the RGB experiment, the training set requires at least 20 colors and at least 6 examples in each class. With at least 40 colors and 15 examples per class, the app also creates a validation set. The Build the dataset section shows the current state of the collection and what is still needed before training and validation can be created; Labeled colors shows the collected samples and, once the dataset has been built, how many were assigned to each set. Auto-label 10 colors adds automatically labeled examples using a rule that estimates how light or dark a color is from a quantity called relative sRGB luminance. Save data exports the collection together with the dataset split, if one has already been created, while Load data restores them from the saved file.

In the sequence experiment, New data generates a different sequence following the same rule. After at least one training epoch, with the network paused, Predict next term calculates the next term from the four most recent available values. Each new term can therefore use earlier predictions as part of its input, until the end of the portion reserved for validation. Remove continuation deletes all added terms. The continuation is also cleared if you resume training or recreate the network.

Importing your own data (CSV/TSV)

Choose Import CSV/TSV to work with your own classification dataset. The file must contain a header row. After loading it, select the Class column and between 2 and 9 numerical columns to use as network inputs. The dataset may contain between 2 and 6 classes, with exactly one class assigned to each example.

The app recognizes comma-, semicolon-, and tab-separated files and shows a preview before importing them. Decimal commas are accepted in semicolon- and tab-separated files. In comma-separated files, numerical inputs must use a decimal point. Column names must be unique, and the selected input columns and class column may not contain missing values. Each file may contain at most 2,000 examples and may not exceed 2 MB.

For every input column, the smallest observed value is mapped to 0 and the largest to 1, with intermediate values scaled proportionally. A column containing only one constant value therefore cannot be used as an input.

A dataset requires at least 20 examples in total and at least 6 examples per class. If it contains at least 40 examples overall and at least 15 examples per class, the app automatically reserves some examples for validation while ensuring that every class is represented in both the training and validation sets. Otherwise, all examples are used for training.

Once the configuration is valid, Use this dataset adds it to the Problem menu. With two inputs, the data are displayed on the two-dimensional plot and activation maps are available. With three or more inputs, the app uses the table view.

The imported dataset remains unchanged throughout the experiment, and New data is not available. Only one imported dataset can be loaded at a time. To use a different file, choose Import CSV/TSV again; the new dataset replaces the previous one.

Files are processed locally in your browser and are not saved between sessions. If you reload the page, you will need to re-import your dataset.

Inspecting examples, Network Internals, and activation maps

During continuous training, examples pass through the network too quickly for their internal values to be displayed. Activations are therefore hidden, and weights and neurons cannot be inspected.

When you press Pause, the app prepares the next example in the current training order using the network’s current parameters. Its prediction is shown immediately; loss and derivatives are calculated when you open the inspection panel. If you resume training, that example is processed first.

To calculate loss and derivatives, you must select an example whose expected result is known.

Click a connection to inspect its weight. The E(w) graph shows how the loss for the selected example would change as that weight varies. It marks the current value and the tangent line. The panel also shows the local direction in which the loss increases, the direction of the update, the derivative, the change Δw, and the new weight value. An expandable explanation shows why the derivative determines the update direction in gradient descent.

Click a neuron and open the Activation tab to see the weighted sum z, the activation a = f(z), the activation-function graph, and its tangent at the current point. The panel also shows f′(z) and explains how it contributes to the changes in weights and biases. The Learn more — error term δ and calculating derivatives panel explains the chain rule, backpropagation, and how the derivatives are calculated.

For problems with two numerical inputs, selecting a hidden neuron while the network is paused also reveals Activation across the input space in the Activation tab. The map shows how the neuron’s activation changes as the inputs vary. It is computed on a grid covering the input domain, independently of the dataset examples, with the current weights and biases held fixed.

Open the map and choose Compare activation maps for all neurons to see an atlas of the hidden-neuron activations, arranged by layer, followed by the network output. For multiclass problems, the atlas shows one probability map for each output. Click any map to return to the corresponding neuron in Network Internals.

Clicking a neuron also lets you inspect its bias. The E(b) graph shows how the loss changes as the bias varies, and the panel provides the corresponding tangent, derivative, update Δb, and new bias value. During One example at a time, inspection remains paused until all three stages are complete.

Enable Pause when tab is hidden to stop training automatically whenever you switch to another browser tab or the page otherwise becomes hidden.
